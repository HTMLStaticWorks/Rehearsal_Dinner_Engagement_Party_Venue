# Velora House — Rehearsal Dinner & Engagement Party Venue

Responsive static HTML/CSS/vanilla JavaScript template. Open `index.html` for Home 1 and `home-2.html` for the distinct Home 2 concept.

## Client requirements addressed
- Spacious page rhythm, restrained content containers and consistent typography.
- Venue spaces, gallery / past-event inspiration, themes, decor and facilities.
- Four-step booking flow: enquire, choose a theme, check availability / tour, confirm.
- Explicit CTAs including Explore Venue, View Past Events, Choose Your Theme, Check Availability and Book a Tour.
- Contact information, directions link and embedded map on Contact.
- Consistent image frames, `object-fit: cover`, aligned split layouts and responsive tablet/mobile breakpoints.

## Before publishing
The displayed brand, phone number, email, address and venue capacity are template/demo content. Confirm them with the actual venue owner before production. Images are referenced from external URLs, so ensure the venue has permission to use them and replace any source that is unavailable. The enquiry form is front-end demo behavior only and needs a backend or form service to deliver submissions.
